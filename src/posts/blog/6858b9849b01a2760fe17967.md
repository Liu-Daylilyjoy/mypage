## 1. Introduction to Data Analysis

Data analysis is the process of inspecting, cleaning, transforming, and modeling data to discover useful information and support decision-making. Python is a powerful language for data analysis due to its simplicity and a rich ecosystem of libraries.

## 3. Loading and Inspecting Data

We often work with CSV files in data analysis. Let’s start by importing necessary libraries and loading data.

```python
import pandas as pd

# Load dataset
df = pd.read_csv('your_dataset.csv')

# View first 5 rows
df.head()
```

Use `.info()` and `.describe()` for a quick overview:

```python
df.info()
df.describe()
```

---

## 4. Data Cleaning

Data is often messy. Common cleaning tasks include:

### Handling Missing Values

```python
# Check for missing values
df.isnull().sum()

# Fill missing values
df.fillna(method='ffill', inplace=True)
```

### Removing Duplicates

```python
df.drop_duplicates(inplace=True)
```

### Data Type Conversion

```python
df['column'] = pd.to_numeric(df['column'], errors='coerce')
```

---

## 5. Exploratory Data Analysis (EDA)

EDA helps understand data distribution, patterns, and anomalies.

```python
# Value counts for a categorical column
df['category'].value_counts()

# Correlation matrix
df.corr()
```

Look for relationships, trends, and outliers that could affect analysis.

---

## 6. Data Visualization

Visualizations help tell the story behind the data.

```python
import matplotlib.pyplot as plt
import seaborn as sns

# Histogram
plt.hist(df['numeric_column'])
plt.title('Distribution')
plt.show()

# Boxplot
sns.boxplot(x='category', y='numeric_column', data=df)

# Heatmap
sns.heatmap(df.corr(), annot=True)
```

---

## 7. Basic Statistical Analysis

Python provides tools for descriptive statistics and basic tests.

```python
import scipy.stats as stats

# Mean, Median, Mode
mean_val = df['column'].mean()
median_val = df['column'].median()
mode_val = df['column'].mode()[0]

# T-test
t_stat, p_val = stats.ttest_ind(df['group1'], df['group2'])
```
